# 魔王城リゾート

勇者に負けて無職になった魔王が、魔王城をテーマパークにして再起を図る、カイロソフト風の経営シミュレーション。
iPhone の Safari で遊ぶ Web アプリ（PWA）。

## 遊び方
1. **建てる** から施設を置く（施設の下側が入口。城門から歩いて届く場所に）
2. 客が城門から入って、好みの施設にお金を落とす
3. 満足した客が口コミで **人気** を上げ、客が増える
4. **研究**ポイント（客1人=1pt）で新しい施設を解放
5. **従業員**（元ボス魔物）を雇って施設に配属すると魅力アップ
6. 30日=1か月。月末に決算。人気で「魔界観光地ランキング」が決まる

## ファイル
- `index.html` / `style.css` … 画面
- `data.js` … 施設・客・従業員・イベントの定義（数値調整はここ）
- `game.js` … ゲーム本体（状態・経路探索・客AI・描画・UI・セーブ）
- `sw.js` / `manifest.webmanifest` … PWA（オフライン・ホーム画面追加）
- `assets/` … 画像（当面は絵文字の仮素材）

## 開発
```
python -m http.server 8080
```
で http://localhost:8080/ を開く。セーブは localStorage（キー `maou-resort-save`）。
